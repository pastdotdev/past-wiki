# About these notes

This folder is the internal wiki of Harbor Loop, a fictional eight-person company that runs
a bike-share telemetry service for small cities. Everything in it is invented. It exists so
a fresh fork of past-wiki has something to ask about in the first five minutes.

Each file is one note. The `date:` in its front matter is when the note was written, and
that is the date past files it under, so it knows which of two notes is the newer one when
they disagree.
